# 재검 진행 상황 트래킹 — 사내 서버 배포판

## 이게 뭔가요 (서버 관리자용 요약)

- **웹앱**: `index.html` 하나. Flask 서버가 그대로 내려줍니다. 별도 빌드(npm 등) 불필요.
- **DB**: `data.db` — SQLite 파일 하나입니다. MySQL/MSSQL 같은 별도 DB 서버 설치가
  필요 없습니다. 이 파일 자체가 데이터베이스입니다. **정기 백업 대상은 이 파일 하나입니다.**
- **서버**: `app.py` — Python(Flask)로 만든 아주 작은 웹서버입니다.
  - `/` : 웹앱 화면
  - `/api/all` `/api/save` `/api/delete` : 데이터 읽기/쓰기 API
- 기존에 쓰시던 다른 DB(예: MSSQL, MySQL)에 붙이고 싶으시면 `app.py`의
  `get_conn()` / SQL 3개 함수(`api_all`, `api_save`, `api_delete`)만 그
  DB에 맞게 바꾸면 됩니다. 데이터 모델이 `(구분, 문서ID, JSON데이터)` 한
  가지 표 형태라 어떤 DB로 옮기든 구조는 동일합니다.

## 요구 사항

- Python 3.9 이상 (사내 서버에 이미 있는지 `python3 --version`으로 확인)
- 그 외 외부 인터넷 접속 불필요 (앱 자체 로직은 전부 로컬에서 동작합니다.
  다만 브라우저에서 이미지·엑셀 내보내기 버튼을 누를 때 `cdnjs.cloudflare.com`에서
  라이브러리 2개(xlsx, html2canvas)를 불러옵니다 — 사내망이 외부 인터넷을 막아뒀다면
  이 두 버튼만 동작하지 않고 나머지 기능은 정상 작동합니다. 필요하면 파일을
  내려받아 로컬 경로로 바꿔드릴 수 있으니 말씀해주세요.)

## 실행 방법

```bash
cd jingum-server-app
pip install -r requirements.txt
python app.py
```

기본 포트는 **8000**입니다. 다른 포트를 쓰려면:

```bash
PORT=9000 python app.py
```

실행 후 사내망에서 `http://서버IP:8000` 으로 접속하면 됩니다. 다른 사내
프로젝트(PQC 점검 등)처럼 서버 관리자분이 정식 접속 주소(도메인/리버스 프록시)를
붙여주시면 그 주소로 다 같이 쓰면 됩니다.

**24시간 상시 구동**이 필요하면(그래야 다들 아무 때나 입력 가능합니다),
서버 관리자분께 아래 중 하나로 등록해달라고 요청하시면 됩니다:
- Linux: `systemd` 서비스 등록, 또는 `pm2`/`supervisor`로 상시 실행
- Windows Server: "작업 스케줄러"로 부팅 시 자동 실행, 또는 IIS + wfastcgi 연동

## 최초 데이터

`seed_data.json`에 기존 엑셀(재검_진행사항)에서 가져온 데이터가 들어있습니다.
`data.db` 파일이 없는 상태로 처음 실행하면 자동으로 한 번만 채워집니다.
이미 `data.db`가 있으면 손대지 않으니 안심하고 재시작하셔도 됩니다.

## 로그인 / 권한

요청하신 대로 별도 로그인 없이 누구나 접속해서 입력할 수 있습니다.
사내망 안에서만 접속 가능한 주소로 두시면 그 자체가 접근 통제가 됩니다.
(외부에서도 접속 가능하게 열 계획이시면, 최소한의 암호 보호를 붙이는 걸
권해드립니다 — 필요하시면 추가해드릴 수 있습니다.)

## 화면 갱신 방식

여러 사람이 동시에 입력하는 걸 서로 보려면 새로고침이 필요한 게 아니라
**20초마다 자동으로 서버에서 최신 데이터를 다시 받아옵니다** (실시간 알림까지는
아니지만, 사실상 실시간처럼 동작합니다). 더 빠르게/느리게 바꾸고 싶으시면
`index.html` 안의 `setInterval(refreshFromServer, 20000)` 부분의 20000(ms)을
바꾸면 됩니다.

## 문의사항이 생기면

- 화면 상단에 빨간 경고("서버에 연결할 수 없습니다…")가 뜨면 → `app.py`가
  꺼져 있거나 주소/포트가 맞지 않는 경우입니다.
- 데이터가 이상하면 → `data.db`를 열어보시거나(SQLite 뷰어, 예: DB Browser
  for SQLite), 저에게 다시 파일을 보여주시면 확인해드릴 수 있습니다.
